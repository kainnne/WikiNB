# 歡迎

這是 **Kainnne**：你的**筆記彙整**與 **AI 提醒助理**。

## 怎麼用

1. 登入網站 → **+ md.**（選資料夾，填檔名／標題／額外關鍵字，再拖入 `.md`）
2. 系統會自動把標題與關鍵字寫進 frontmatter 並推上 GitHub Pages（約 1–2 分鐘）
3. 管理頁可改「顯示標題」（不改檔名）

之後可問 Codex：我寫過什麼、怎麼複習、下一步學什麼。
