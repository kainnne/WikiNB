# Python 基礎迭代練習

這組七天練習用短小程式建立 Python 的基本操作感，內容從輸出清單元素，逐步加入條件判斷、累加、索引與問題修正。

## 練習主題

- 建立與遍歷 list。
- 使用 `for` 迴圈處理一組資料。
- 在迴圈內加入 `if` 條件。
- 累加數值、計算結果並輸出。
- 比較原始解法與修正版，理解錯誤發生的位置。

## 真正要建立的能力

基礎題目的價值不只是記住語法，而是學會逐步觀察程式狀態：目前處理哪個元素、變數何時更新、條件何時成立、輸出為什麼和預期不同。這種拆解方式之後同樣適用於資料處理、模型訓練與 API 除錯。

## 下一步

將現有題目補上預期輸出與自動測試，再延伸到函式、字典、檔案讀寫與例外處理。每次新增概念時保留一個最小可執行範例，讓 AI 協助時也能快速定位問題。
