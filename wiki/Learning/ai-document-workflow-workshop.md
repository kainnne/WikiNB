# AI 文件與 Agent 工作流實作

這次工作坊的重點不是單次提示詞，而是把 AI 任務整理成可重複、可檢查、可交接的流程。完成內容涵蓋六種常見辦公與知識工作情境。

## 完成的練習

- 依需求產出不同課程公告，維持格式與對象差異。
- 把簡報結構與視覺規則整理成可重用 Skill，並用新題目驗證。
- 清理規章來源、建立問答助手，並用十組問題留下驗收紀錄。
- 將印表機故障排除整理成具分支與升級條件的 Agent 流程。
- 建立報價單檢核 Skill，比對欄位、條件與異常。
- 彙整採購資訊並產出檢核摘要與會議備忘錄。

## 共同方法

先辨識來源事實，再建立輸出結構，接著列出可觀察的驗收條件，最後用不同案例測試。對涉及規章、報價與採購的任務，AI 只能協助整理與找出疑點，不能取代授權人員的最終判斷。

## 對後續工作的影響

可重用能力應寫成 Skill 或簡短規則；專案事實留在該專案；公開 Wiki 只保留不含敏感資料的方法與成果。這種分層能避免每個 Agent 重讀所有課程材料，也能降低把練習資料誤當真實組織資訊的風險。
