# N11 檢索與 Index Agent

RAG 先檢索相關資料，再把資料交給模型生成回答。這與重新訓練模型不同：文件放進索引後，模型權重不會因此自動改變。

Index 組織可搜尋的內容，Embedding 把內容表示成可比較的向量，Retrieval 找出候選片段。切段、文字搜尋和排序也會影響結果，不能把所有查不到都歸因於模型。

## 用三份假維護文件做練習

一份說溫度警示，一份說保養頻率，一份說現場聯絡方式。問「A-17 過熱後該先做什麼？」時，先確認檢索真的找到相關規則，再檢查回答是否使用了那段內容。

如果文件沒有設備型號的處置規則，應說明缺口，不能借用另一個型號的規則當成答案。引用連結讓人能查來源，但連結存在不保證引用的段落支持這句結論。

文件權限應限制哪些資料可被檢索或送進模型，也要處理快取與日誌。只在最後畫面隱藏一段文字，無法保證它沒有先進入上下文。

## 練習

準備可回答、沒有答案、含不同型號規則、無權限文件四種問題。保留檢索片段、來源與最終回應，逐一判斷回答是否有足夠支持。

自我檢查：能定位失敗發生在索引、檢索、權限篩選還是文字生成；不知道時不讓模型填滿空白。
