# 單元 0：先分清一首歌的六層工作

> 課程首頁：[[Learning/suno-studio-album-production]]

傳統製作裡，一首歌會經過詞曲、編曲、演出、錄音、編輯、混音與母帶。Suno 可能在幾分鐘內把它們一起交出來，方便卻也容易讓問題混在一起。第一項基本功，是聽到不滿意時能說出「壞在哪一層」。

## 本單元完成條件

你要能拿一首 Suno 作品，逐層回答：

1. 若換一個音色但音符不變，問題會改善嗎？
2. 若保留編曲但換歌手，問題會改善嗎？
3. 若只調音量與空間，問題會改善嗎？
4. 這個問題該重生、局部替換、剪輯，還是混音？

## 六層心智模型

```text
概念與詞曲
  ↓ 決定旋律、和聲、歌詞與段落
編曲與音色
  ↓ 決定誰在何時演奏、密度與音域
演出與演唱
  ↓ 決定語氣、咬字、力度、timing 與表情
錄音／生成音訊
  ↓ 把表演變成 waveform
編輯
  ↓ 切割、排列、對齊、淡化、替換與修復
混音與 automation
  ↓ 建立平衡、清晰、空間與隨時間變化
母帶與交付
  ↓ 統一整體播放感、格式、metadata 與版本
```

### 1. 詞曲問題

症狀包括旋律沒有辨識度、副歌不像副歌、歌詞重音彆扭、和聲沒有方向。這些問題靠 EQ 很難救。應回到 lyrics、段落安排或重新生成核心素材。

### 2. 編曲問題

症狀包括所有樂器從頭到尾都在、主唱被中頻淹沒、主歌已經太滿、高潮沒有新元素、低頻角色互相打架。先調整樂器進出、音域和密度，再談混音。

### 3. 演出問題

症狀包括主唱情緒不對、字尾奇怪、鼓太僵、樂句缺乏呼吸。若表演本身不成立，compression 只會把問題變得更清楚。通常要換 take、換生成版本或局部重做。

### 4. 音訊與編輯問題

症狀包括接縫爆音、拍點略為提前或落後、尾音被切斷、tempo drift、拉伸造成顆粒感。解法可能是移動 clip、warp、crossfade、改用原速，或替換瑕疵區段。

### 5. 混音問題

症狀包括人聲忽大忽小、低頻混濁、齒音突出、空間扁平或聲像失衡。這時才用 gain、EQ、compression、pan、reverb、delay 和 automation。

### 6. 母帶與交付問題

母帶不是「最後再套一個變大聲插件」。它處理的是整體播放感、曲目間一致、峰值與輸出格式。若單曲平衡仍然不好，應退回混音，而不是靠 master 修正。

## DAW 裡最重要的物件

| 名詞 | 白話定義 | 常見誤判 |
| --- | --- | --- |
| Track | 一條聲音或控制通道 | 不是一件樂器永遠只能有一條 track |
| Clip／Region | 放在時間軸上的一段 audio 或 MIDI | 它可以被非破壞性剪輯，不等於改壞原檔 |
| Audio | 已經錄下或生成的 waveform | 不能像 MIDI 一樣任意改每顆音符 |
| MIDI | 音高、時間、力度與控制資料 | MIDI 本身沒有聲音，要交給樂器發聲 |
| Stem | 從混音拆出的較大聲部或匯出的分軌 | AI 分 stem 不是拿回原始錄音軌，可能有殘留與相位問題 |
| Bus／Main | 多條 track 匯集與共同處理的位置 | 在 Main 上處理不會自動修好單一軌的問題 |
| Automation | 參數隨時間移動的曲線 | 不是只能做音量淡入淡出 |

## Signal flow：聲音經過什麼

最簡化的路徑是：

```text
Clip → Clip gain／warp → Track effects → Track fader／pan → Main → Export
```

效果器順序會改變結果。先 distortion 再 reverb，會把失真後的聲音放進空間；先 reverb 再 distortion，連殘響也一起被扭曲。沒有唯一正確順序，但每一步都要能說明目的。

## 一次只診斷一層

拿一首生成曲，做三輪聆聽：

### 歌曲輪

先忽略音色是否高級，只問旋律、歌詞、和聲與段落是否成立。若副歌拿掉製作後仍沒有記憶點，標為詞曲問題。

### 編曲輪

畫出每八小節有哪些角色進出。若副歌只是所有軌一起變大聲，卻沒有新節奏、和聲或音域，就標為編曲問題。

### 音訊輪

用耳機與喇叭各聽一次，檢查拍點、人聲字尾、低頻、左右平衡、AI 顆粒與接縫。把時間碼寫下來，不用「整體怪怪的」代替證據。

## 常見誤判

- 「不好聽就重生」：局部接縫或音量問題可能只需編輯。
- 「混音能救旋律」：混音不能替副歌發明 hook。
- 「stem 等於乾淨 multitrack」：分離演算法只能估計來源。
- 「越多層越專業」：每一層都要有功能，否則只是遮蔽。
- 「master 越響越完成」：大聲會讓短時間比較更討喜，卻不代表平衡更好。

## 練習：問題分類表

選一首作品，記錄五個時間碼。每個時間碼只能先放進一類：詞曲、編曲、演出、編輯、混音。接著為每一項寫出最小修正，例如「副歌第一句旋律重生」或「2:14 尾音做 30–80 ms crossfade」，不能只寫「再調一下」。

若你能在不開插件的情況下先決定修正層級，就完成本單元。
