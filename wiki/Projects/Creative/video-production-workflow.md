# 從逐字稿到影片：讓內容、畫面和聲音一起成立

我希望影片看得下去，也能在需要時修得動。製作時先留下可編輯的內容、畫面和聲音來源，之後改一句話、換一張圖，才不用整片重新猜一次。

這篇整理的是製作方法，沒有公開私人逐字稿、聲音素材或品牌專屬檔案。各支影片的觀眾、風格與交付規格，仍要依當次需求決定。

## 先知道觀眾需要看懂什麼

開始前，先說清楚影片要讓誰看、看完能理解或完成什麼，以及播放情境。課程操作示範需要讓人看清楚動作；作品介紹可能更重視整體感受。兩者不必套同一種節奏。

旁白尊重觀眾原有的能力。對方不熟 AI，不代表不會編輯文件或判斷工作需求。把時間留給真正陌生的概念，普通操作能用畫面交代，就不必每一步都再唸一次。

資訊量也不靠片長決定。一段只有一個清楚概念，可以很短；需要例子支撐的地方，就把例子說完。不要為了讓每張字卡同樣整齊，把句子剪成難懂的標語。

## 留住定稿，再安排製作版本

先整理口述、筆記與既有素材，完成逐字稿及可編輯頁面。頁面可以用簡報，也可以是已有的場景工程；重點是文字、圖片與構圖能逐項修正。

當使用者確認定稿，保存那一份來源。朗讀稿、字幕、畫面短句各自從它衍生，不反過來覆蓋原文。畫面只顯示關鍵字，不代表旁白也要刪到同樣長度。發現事實問題時先提出差異，不能用「潤稿」名義悄悄改定稿。

版本紀錄至少要找得到定稿、使用的素材、原始配音、字幕、場景設定與最後輸出。雜湊可以協助確認檔案是否相同，但仍要能理解哪一版對應哪個成品。

## 分鏡跟著意思走

分鏡先回答「這句話說到這裡，觀眾應該看哪裡」。當前內容清楚，才決定用聚焦、操作放大、物件動畫或轉場。

例如，介紹一個檔案整理流程，可以先顯示凌亂的檔案，再隨旁白逐步收進資料夾，最後停在整理結果。若從頭到尾放著完整流程圖，觀眾得自己找正在講哪一步；若每個物件一直移動，注意力又會被分散。

同一張畫面可以分幾次揭露，不必每說一句就換頁。需要比較 A、B 時，兩邊要有足夠的辨識與停留時間。操作倒數、連結與 QR Code 的閱讀時間，也要留在時間軸裡。

## 動態要符合承諾的內容

要呈現人物走路、招手或翻書，就檢查人物是否真的有動作。平移一張人物圖、加粒子或慢慢放大，表達的是鏡頭效果，無法證明人物動了。

靜態圖片需要讓人觀察細節時，維持穩定就很好。不是每張圖都要漂移，也不是每個轉場都要用透視翻面。循環影片則要看接點、端點停頓與反向動作，確認播放起來自然。

工具做不到所需動作時，先說明限制，提供可採用的替代畫面。不要在交付時把另一種效果稱作原本要求的動態。

## 先確認聲音，再做整段

新聲線或語氣尚未確定時，先做短樣音。已選好的聲音與風格則沿用，不必每次重問，也不要為了修音量反覆生成全片。使用真人音色時，先確認聲音使用與上傳服務的授權；某次個人作品的選擇，不會自動變成其他品牌或使用者的預設。

原音、處理後旁白、音樂和音效分軌保存。想要親切、溫暖、有一點空間感，可以從表演與混音調整；提高音量或加很多回音，通常不能解決語氣不自然。

先判斷問題在哪一層：

| 聽到的問題 | 優先檢查 |
| --- | --- |
| 某段突然太小 | 原音、活躍語音音量與段落接縫 |
| 句尾太像宣傳播報 | 原始語氣與生成版本 |
| 字聽不清楚 | 配樂遮蔽、回音與咬字 |
| 轉場連響很吵 | 音效事件是否過密或重複 |

數值能協助定位問題，不能替人判斷聲音是否舒服。整片平均響度正常，也可能有一段特別小；未編碼音檔沒有爆音，最後壓縮成片的峰值仍須重測。

## 換圖與音效當成同一個事件設計

A 圖飛出、B 圖飛入，通常是一個換圖事件。若飛出、飛入、落點各響一次，幾個短音就容易擠在一起。

先排視覺動作，再為需要的重點放聲音。除了波形有沒有重疊，也要聽兩個提示是否靠得太近。音效的功能是幫觀眾感受到重點，不是替每個動畫打勾。

背景音樂要有存在感，又不搶旁白。比例依原始素材和播放環境調整，不把某支影片的增益、響度或殘響參數當作通用配方。

## 字幕取字與時間對齊分開做

字幕文字以確認過的稿件為準，時間以實際音檔對齊。語音辨識可能把專有名詞聽錯，也可能漏標點；它適合協助定位，不能直接取代定稿。

字幕依自然語句切成一至兩行，並檢查實際畫面的安全區。修改停頓、刪一句話或換配音，都會影響後面的字幕、焦點和音效時間，這些要一起更新。

## 檢查最後輸出的檔案

工程預覽正常，還要看最終影片。至少核對字幕與定稿、畫面重點與旁白、字幕安全區、轉場接點、聲音比例，以及最後檔案能否完整解碼。QR Code 要從成片畫面解碼，不能只檢查原始圖片。

只改聲音時，盡量保留原視覺；只換一頁時，重做受影響場景與接點。改稿或剪片則要重新計算相關時間。每次另存新版，避免新輸出覆寫到舊版本依賴的素材。

交付影片之外，依需要附逐字稿、字幕與可編輯頁面。若交付 PPTX，同時提供同版本轉出的 PDF 並核對頁序和版面。完整私人工程、帳號設定與未授權素材留在工作區。

最後分清楚：哪些已做技術檢查、哪些已實際看過或聽過、哪些主觀效果仍待確認。這樣下一次修訂才知道從哪裡接手。
