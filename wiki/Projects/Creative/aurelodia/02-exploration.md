# Aurelodia 的探索玩法

這一篇說明在 Aurelodia（奧雷洛迪亞）的世界裡怎麼移動、能做什麼。網頁版的探索現在就能玩：https://aurelodia.kainnne.com/ 。世界與音樂的對應在 [[Projects/Creative/aurelodia/01-world-and-music]]，入口頁在 [[Projects/Creative/aurelodia]]。

## 探索沒有目標、分數與計時

探索模式裡沒有分數，也沒有計時。歌曲在玩家走到哪裡都持續播放，玩家只需要移動，看畫面怎麼跟著音樂變化。站在一座島上，就是在聽這座島的歌。

## 能做的事

| 動作 | 說明 |
|---|---|
| 走與跑 | 在島的地面上移動 |
| 起飛與飛行 | 離開地面，在空中自由飛。落下的途中再按一次起飛，可以接回飛行 |
| 兩段加速 | 飛行時可以加速；連按兩下加速鍵並按住，進入第二段，速度更快。對戰中沒有第二段加速 |
| 滯空 | 在空中停住不動，適合看一座建築 |
| 光波 | 放出一道光波，附近的東西會用畫面與聲音回應。光波的音高取自當下的和弦 |
| 星圖 | 一張列出所有歌的地圖，選一首就能飛過去 |
| 天際 | 飛到足夠的高度，會進入島與島之間的空間（世界之間） |

桌機用鍵盤與滑鼠，手機用觸控（左邊搖桿控制移動，右邊控制視角）。

### 走到另一座島

兩種方式：

1. **航環**：飛過島緣的金色航環，被帶到鄰島。航環的樣子預告對面那首歌的拍子與旋律，說明在 [[Projects/Creative/aurelodia/01-world-and-music]]。
2. **星圖**：從星圖選一首歌，直接前往。

如果飛出島外，會被金線接回最近的一座島，不會掉下去。

### 互動靠碰觸，不靠點擊

玩家用人物去碰世界裡的東西，不點選單或按鈕來觸發它們。光波是主動的互動：放出光波，附近的物件會回應。

### 人物造型

人物造型跟著所在的島換，由島的建築型態與角色性別決定，玩家不用選。換造型時模型以點陣溶解的方式切換，落在拍點上。

## 主選單就是開放世界

進遊戲沒有獨立的標題畫面。載入完成後，玩家就站在編號 000 的主題曲島上，已經可以走、跑、飛。主選單疊在畫面的左側，半透明，玻璃材質配金色細線邊框。

主選單的項目有：

- **Create room**：開一局，可以選是否先玩導覽。桌面完整版可以選人數與電腦對手；網頁版固定是玩家加 2 個電腦。
- **Join room** 與 **Ranked**：項目看得到，但連線還沒做，目前進不去。
- **Settings**：設定。

主選單的規則：

- 音樂不會因為打開選單而停。玩家飛到哪座島，打開選單時就繼續播那座島的歌，直到按下 Start，畫面與音樂一起淡出。
- 按 Start 時玩家站的那座島，就是玩家為這一局選的歌與造型。
- 選單開著時，開放世界仍然可以操作。
- 進入對局之後的世界不從主題曲開始，而是這一局特製的世界（見 [[Projects/Creative/aurelodia/03-battle]]）。

主選單目前在開發中，樣子與細節還會調整。

## 歌名與編號常駐

畫面上一直顯示所在那座島的編號、歌名、音樂術語與風格，帶一點透明度。飛到另一座島，顯示就跟著換。

## 網頁版的新手提示（開發中）

網頁版規劃在第一次進來時，用一個小動畫帶玩家做兩件事：先按起飛，飛起來之後再按加速，做完就不再出現。
