# WikiNB for KCIS 教學知識庫

WikiNB for KCIS 是 WikiNB 在教學與組織情境中的延伸。它希望讓教師把常用教材、流程、教學筆記與問題整理成可瀏覽的知識庫，並在需要時透過 AI 協助查找與說明。

## 主要功能方向

- 用 GitHub Pages 提供不依賴特定電腦的閱讀介面。
- 透過本機服務處理需要登入或本機 Codex 的管理功能。
- 支援教師新增 Markdown 筆記、分類內容並同步版本。
- 保留人類可直接閱讀的層級與目錄，不讓知識只存在於聊天紀錄。

## 設計價值

教學知識常散落在個人資料夾、訊息與臨時文件中。這個版本的重點是把「某個人記得」變成「團隊能找到、能理解、能持續更新」，同時保留資料權限與人工確認。

## 安全邊界

公開說明只描述產品能力，不公開師生個資、校內文件、登入資訊或內部網路設定。實際部署需要依組織政策區分公開內容、授權內容與完全不應交給外部模型的資料。
