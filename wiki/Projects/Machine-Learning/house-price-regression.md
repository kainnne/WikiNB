# 房價迴歸模型與 API 專案

這個專案把一個迴歸題目從資料準備推進到可呼叫的服務：先建立合成房價資料，訓練與評估模型，再保存模型並以 FastAPI 提供推論端點。

## 完成內容

- 建立 5,000 筆合成樣本，涵蓋房屋大小、屋齡、捷運距離、樓層、區域評分與市場條件。
- 以固定的訓練／測試切分建立可重現評估流程。
- 使用 Random Forest Regression 建模並保存產物。
- 建立 HTTP API，讓其他前端或服務能提交房屋條件並取得預測值。
- 加入健康檢查與基本輸入驗證，將 notebook／腳本成果轉成可測試服務。

## 實驗結果

在該合成測試集上，模型得到約 `R² = 0.9852`、`RMSE = 91.06`、`MAE = 73.35`。這些數字證明流程與資料生成規則能被模型學到，但不代表對真實房市也有相同準確度。

## 最重要的限制

資料是合成的，目標值也由預先設計的關係產生，因此高分不能直接當成商業預測能力。若要走向真實應用，必須處理資料來源、時間漂移、地理差異、價格單位、偏誤與監控，並以真實留出資料重新驗證。
